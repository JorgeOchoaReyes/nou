# Project Overview
## What is this project?
This project is a new software development initiative.

## Getting Started
### Build, Test, and Run
* `npm install` : Installs dependencies specified in package.json file.
* `npm run dev` : Runs the development script which compiles and runs index.ts file using npx tsx command.

## Project Details
### Tech Stack Used
This project uses TypeScript as its primary programming language. The tech stack includes:
 * ESLint for code linting
 * Jest (via Jiti) for testing
 * Chalk, CLI Highlight, Ollama, ShellJS, and Zod libraries for various functionalities
 * Typescript-EsLint for enforcing typescript best practices
